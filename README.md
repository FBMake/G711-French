# G711 en français

Convertisseur de fichiers audio pour la téléphonie (musique d'attente, annonces SVI), en français.

Page statique unique : ouvrez `index.html` dans un navigateur ou hébergez-la (par ex. GitHub Pages). La conversion se fait entièrement dans le navigateur.

Formats pris en charge : WAV µ-law, WAV A-law, WAV PCM 8 bits, WAV PCM 16 bits (8 kHz et 16 kHz), RAW Asterisk (.sln). G.722 et G.729 ne sont pas disponibles dans le navigateur.
